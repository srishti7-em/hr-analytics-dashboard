## Project Overview
An end-to-end HR Analytics Dashboard built using the IBM HR Analytics Employee Attrition dataset. The project processes 1,470 employee records to generate insights on attrition, salary, performance, and workforce demographics.

---

- reports/ → Business insights report

## Technologies Used
- Python 3, Pandas, NumPy
- Matplotlib, Seaborn, Plotly
- SQL (SQLite)
- Power BI Desktop
- GitHub

---

## Key Findings
- Overall attrition rate: 16.1%
- Sales department has highest attrition: 20.6%
- Low salary band employees leave at 2.5x the rate of high earners
- Employees with 0-2 years tenure have highest attrition
